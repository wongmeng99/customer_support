# App crashes or freezes
Clear the app cache, update to the latest version, and restart your device. If the crash continues, reinstall the app and send us the app version and device model.

# Upload errors
Files must be under 100 MB. Supported formats: PDF, PNG, JPG, CSV, DOCX. A 500 error on upload is usually temporary; retry after a few minutes and check the status page.

# Notifications not working
Check that notifications are enabled in the device system settings and in the app under Settings > Notifications. Disable battery-saver mode for the app, then log out and back in.

# Service status
Live incidents and maintenance are listed at status.example.com. Subscribe there for updates.

# Slow performance
Check your internet connection, close other heavy apps, and update to the latest version. Try a different network to rule out connectivity issues.

# API timeouts
If the API returns timeouts, check status.example.com for live incidents first. Retry with exponential backoff, confirm your network and firewall allow outbound requests, and reduce request payload size. If timeouts continue, contact support with the endpoint, timestamps, and request IDs.

# Export to CSV is empty
An empty CSV usually means the active filters or date range return no rows. Clear filters, widen the date range, and export again. Also check that your browser allows downloads and try a different browser. If the file is still empty, contact support with the report name and filters used.

# Page won't load in Safari
Update Safari to the latest version, clear website data for our site (Safari > Settings > Privacy > Manage Website Data), disable content blockers and extensions, and reload. If it still fails, try a private window or another browser and send us your Safari version.

# App problems and refunds
If the app keeps crashing, follow the steps in "App crashes or freezes" first. If the problem continues and you want your money back, request a refund in Settings > Billing > Request refund, or contact support within 30 days of the charge. Include your app version and device model so we can also fix the crash.
